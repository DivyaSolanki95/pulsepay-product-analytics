# Project Charter — PulsePay

## Objective
Build a realistic end-to-end Product Analytics portfolio project that demonstrates product sense, SQL, experimentation, statistics, Python, visualization, business communication, and technical execution.

## Primary stakeholder questions
1. Is the product growing sustainably?
2. Where do users drop off?
3. What behaviors predict activation and retention?
4. Which acquisition channels produce high-quality users?
5. Why did a key metric change?
6. Did a product experiment work?
7. What should the product team prioritize next?

## Product Analyst principle
Every analysis should end with:
1. Observation
2. Diagnosis
3. Impact
4. Recommendation
5. Measurement

## Scope
### Phase 1 — Data foundation
MySQL schema, event taxonomy, realistic synthetic dataset.

### Phase 2 — Core product analytics
Funnels, activation, retention, cohorts, feature adoption, segmentation.

### Phase 3 — Experimentation
A/B testing, significance testing, guardrails, recommendations.

### Phase 4 — Product intelligence
Anomaly detection, churn risk, voice-of-customer analysis.

### Phase 5 — Experience and portfolio
Dashboard, case study, polished GitHub repository, demo, deployment.
